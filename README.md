# lucario-siem-lab
Home SIEM lab that senses attacker activity in Windows, Linux &amp; firewall logs using Splunk and custom detection rules.

## 🔵 Why "Lucario"?

In the Pokémon world, Lucario is known as the **Aura Pokémon**. It can sense
the aura that every living thing gives off, even when someone is hiding
behind a wall or far away.

A SIEM works the same way. Every machine on a network constantly gives off
**logs**: logins, processes, connections. This lab collects that "aura" from
every machine and uses detection rules to **sense attackers hiding inside
normal activity**.

| Lucario | Lucario SIEM Lab |
|---|---|
| Every creature gives off aura | Every machine gives off logs |
| Senses aura from far away | Centralizes logs from all VMs into Splunk |
| Spots enemies hiding by their aura | Detection rules spot attackers hiding in normal traffic |
| Steel/Fighting type: defends *and* counters | Detects threats *and* triages them end-to-end |

The theme carries through the whole project:
- **Evolution = project phases.** Riolu (basic lab) → Lucario (full lab) → Mega Lucario (cloud version)
- **Detection rules are named after attack moves.** Like Aura Sphere, a move that never misses, the brute-force rule is built to catch every attempt.
